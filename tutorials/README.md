# OpenCommerce Platform — Tutorials

A complete, step-by-step tutorial of the OpenCommerce Platform project, available in two languages.

- 🇮🇷 **فارسی**: [`fa/00-فهرست-مطالب.md`](fa/00-فهرست-مطالب.md)
- 🇬🇧 **English**: [`en/00-table-of-contents.md`](en/00-table-of-contents.md)

Each language folder contains 23 numbered files (00–22), meant to be read in order — from the project's vision and architecture, through every module and every phase of the AI Agent Orchestrator, to a hands-on guide for installing, running, and testing the live Showcase demo, how others can integrate with or build on the project themselves (including the real Zibal + Stripe payment gateways), a practical guide to every official SDK (PHP, Laravel, Python, Node.js/TypeScript, Go), and finally a guide to real, revenue-generating ways to use the project.

**New to software engineering, or to AI agent concepts?** Each language folder also has a `pre-tutorial/` subfolder — 12 additional, optional chapters covering every technical term and concept used anywhere in this project (web/API fundamentals, databases, software architecture, Domain-Driven Design, design patterns, Laravel, security, testing, LLMs/AI agents, the MCP protocol, online payments, and professional/business concepts), each one explained from zero and tied to a real, concrete example from this project's own code. Read it before file 00 above if any of those terms feel unfamiliar; skip it entirely if they don't.

Both versions cover the same content and follow the same structure; pick whichever language you're more comfortable reading in.

For the deepest technical detail, the project's own `HANDOFF.md` (at the repository root) remains the final authority — this tutorial is a guided, narrated distillation of it.
